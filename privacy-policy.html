О демонстрационном проекте

Этот сайт показывает дизайн и структуру сайта тренера из портфолио разработки. Описания услуг и цены служат элементами демонстрационного макета. Через сайт нельзя записаться на тренировку, получить консультацию, оформить заказ или отправить заявку.

Функции демоверсии

Форм ввода контактов, регистрации, загрузки файлов, приема оплаты и чата здесь нет. Счетчики веб-аналитики и связанные обработчики удалены. Шрифты, изображения и используемые скрипты загружаются с домена сайта. Выбор оформления меняет только текущую страницу и не записывается кодом сайта в хранилище браузера.

Здесь нет клиентских отзывов, анкет и галереи клиентов. Личные фотографии владельца проекта используются для демонстрации оформления. Кнопки, которые прежде вели к записи или переписке, открывают это описание демоверсии.

Технические сведения хостинга

Страницы размещены на GitHub Pages. При их открытии браузер обращается к хостингу, который получает технические сведения запроса, включая IP-адрес. GitHub сообщает о хранении IP для безопасности инфраструктуры. Отсутствие форм и счетчиков не отключает журналы хостинга. Мы не утверждаем полного отсутствия обработки технических данных или их исключительно российского размещения.

Сведения GitHub Pages. При переходе по внешней ссылке действуют правила выбранного ресурса. Посещение этой демоверсии не подписывает на рекламу и не считается согласием на произвольное использование данных.
